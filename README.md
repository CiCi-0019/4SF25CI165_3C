# Skill Lab – CIE 1: FC Barcelona Squad History Analysis

## Overview
This project analyzes the FC Barcelona squad history dataset using Python, Pandas, NumPy, Matplotlib and Seaborn.

## Files
- `Skill_Lab_CIE_1.ipynb` – Jupyter Notebook containing the complete step-by-step analysis.
- `dataset.csv` – CSV dataset used in the analysis.

## Tasks covered
1. Reading the CSV file using Pandas.
2. Understanding the dataset using `head()`, `tail()`, `info()` and `describe()`.
3. Data transformation, including datetime conversion and derived columns.
4. Identifying null values and applying mean imputation to the numerical `player_age` column.
5. Generating insights using grouping and aggregation.
6. Visualizing findings using charts.

## Run the notebook
1. Open this folder in Visual Studio Code.
2. Install the Python and Jupyter extensions if they are not already installed.
3. Install dependencies in the VS Code terminal:

   `python -m pip install pandas numpy matplotlib seaborn ipykernel`

4. Open `Skill_Lab_CIE_1.ipynb`.
5. Select a Python kernel.
6. Run all cells from top to bottom.

Keep `dataset.csv` in the same folder as the notebook.
